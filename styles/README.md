# Map styles

This directory holds the MapLibre styles used by the app.

## `bundled/` (packaged into the APK)

`bundled/` is an Android assets directory, so `bundled/map/...` is loaded as `asset://map/...`.

- `map/style-light.json`: the Day style. Generated by [`pipeline/style/`](../pipeline/style/), never
  edited by hand. We currently use the **Protomaps basemaps v4 tile schema and style**
  (BSD-3-Clause, visual design CC0, see `map/LICENSE-protomaps-basemaps.md`). The tile source URL is
  a placeholder that the app replaces with the installed region file.
- `map/glyphs/`: Noto Sans glyph ranges (OFL-1.1, `map/glyphs/OFL.txt`). See
  [docs/GLYPHS.md](../docs/GLYPHS.md).
- `map/sprites/`: the Protomaps `light` sprites, 1x and 2x (MIT, from tangrams/icons,
  `map/sprites/LICENSE.md`).

Sources, licences and per-file SHA-256 are in [docs/THIRD_PARTY.md](../docs/THIRD_PARTY.md).

## Rules

- Styles are written for our own tile schema, produced by `pipeline/` (for now that schema is
  Protomaps basemaps v4, see above).
- Styles reference only bundled or on-device resources: no `http://` or `https://` URLs.
- Never copy styles, icons or sprites from other map apps or services.
- Icons must be original or under an open licence compatible with GPL-3.0 (e.g. CC0, MIT,
  Apache-2.0, OFL for icon fonts), and recorded in [docs/THIRD_PARTY.md](../docs/THIRD_PARTY.md).
- Fonts for glyphs: Noto (SIL OFL 1.1). Ship the OFL text with the glyphs.
- Every style shows "© OpenStreetMap contributors".
